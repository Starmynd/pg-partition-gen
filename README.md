# pg-partition-gen

Generate PostgreSQL declarative range partition DDL for tables keyed by a
date or timestamp column. One file, standard library only.

Instead of hand-writing 60 `PARTITION OF` statements (and getting one boundary
wrong), describe the span and let the generator emit aligned DDL.

## Features

- `day` / `month` / `year` periods with correctly aligned boundaries
- `DEFAULT` partition included
- Identifiers are double-quoted; optional schema qualifier
- Refuses absurd spans (e.g. 1000+ daily partitions) with a clear error
- `--out FILE` or stdout

## Usage

```console
$ pg-partition-gen --table events --column created_at \
      --start 2026-01-01 --end 2026-03-31 --period month
-- Generated by pg-partition-gen (month partitions)
-- The tool does not introspect your schema: review and fill in
-- the column list before running this DDL.
CREATE TABLE IF NOT EXISTS "events" (
    -- id         bigint GENERATED ALWAYS AS IDENTITY,
    -- created_at timestamptz NOT NULL
) PARTITION BY RANGE ("created_at");

CREATE TABLE IF NOT EXISTS "events_2026_01" PARTITION OF "events" FOR VALUES FROM ('2026-01-01') TO ('2026-02-01');
CREATE TABLE IF NOT EXISTS "events_2026_02" PARTITION OF "events" FOR VALUES FROM ('2026-02-01') TO ('2026-03-01');
CREATE TABLE IF NOT EXISTS "events_2026_03" PARTITION OF "events" FOR VALUES FROM ('2026-03-01') TO ('2026-04-01');

CREATE TABLE IF NOT EXISTS "events_default" PARTITION OF "events" DEFAULT;

$ python3 pg_partition_gen.py --test
selftest: failures=0
```

## Notes

- Review the column list in the header before executing: the tool does not
  connect to your database or introspect existing tables.
- For an existing non-partitioned table the usual recipe is: create the new
  partitioned table, copy data, rename. Generate both halves with this tool.

## Testing

```console
$ python3 pg_partition_gen.py --test
```

Covers monthly/daily/yearly boundaries (including a 28-day February across a
month edge), alignment to Jan 1 for year partitions, the DEFAULT partition
and input validation.
